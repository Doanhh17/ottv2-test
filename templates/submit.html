Bot Python mẫu

Lưu đoạn mã dưới đây thành tệp .py. Đây là bot đơn giản để thử nộp bài, chưa phải chiến thuật tối ưu.

def make_move(board, valid_moves, player):
    # Ưu tiên đi thẳng tới căn cứ đối phương nếu có thể.
    goal = (8, 8) if player == 1 else (0, 0)
    for move in valid_moves:
        if move[1] == goal:
            return move

    # Nếu chưa thể thắng ngay, trả về một nước hợp lệ.
    return valid_moves[0]

Bắt buộc định nghĩa hàm đồng bộ make_move(board, valid_moves, player) và trả về một nước trong valid_moves. Mỗi quân trên bàn là "1R", "2S"...; ô trống là None.
